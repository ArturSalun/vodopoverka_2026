# VODOPOVERKA - Water Meter Verification Service

[![Netlify Status](https://api.netlify.com/api/v1/badges/79202ca1-5f53-42d7-ac82-2fcbf33bc8a2/deploy-status)](https://app.netlify.com/sites/vodopoverka/deploys)

Professional water meter verification service in Kharkiv, Ukraine. This website provides information about our services, pricing, and allows customers to schedule meter verifications.

## Features

- Bilingual support (Ukrainian and Russian)
- Online service request form
- Real-time appointment scheduling
- Service status tracking
- SERRP system integration
- Admin panel for request management
- Responsive design for all devices

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Supabase
- EmailJS
- Vite

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

The site is automatically deployed to Netlify on every push to the main branch.

Visit: [vodopoverka.netlify.app](https://vodopoverka.netlify.app)
